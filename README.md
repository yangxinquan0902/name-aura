# 名相 · NAME AURA

> 一个昵称，藏着一个人的光谱。

输入微信名或昵称，读出 TA 的**性格底色、人品牌照、深交潜力**。纯静态、零依赖、双击即开。

![纯静态](https://img.shields.io/badge/build-none-07C160) ![零依赖](https://img.shields.io/badge/deps-0-7C5CE6) ![license](https://img.shields.io/badge/license-MIT-4A443D)

---

## 特性

**17 个判断维度**

| 维度组 | 指标 |
| --- | --- |
| DISC 四象 | 主导力 D · 感染力 I · 稳定力 S · 严谨力 C |
| 大五人格 | 开放性 · 尽责性 · 外向性 · 宜人性 · 稳定性 |
| 人品牌照 | 真诚度 · 靠谱指数 · 共情力 · 边界感 · 担当力 |
| 深交潜力 | 灵魂浓度 · 长期主义 · 治愈力 · 有趣指数 → 综合**深交指数** |

**评分与等级**：综合魅力值 70–99，配 S / A+ / A / B+ / B 五档与"超过 x% 的昵称"排名感。

**12 种人格原型**：由"主导 × 次要"组合映射，每个原型带动物形象、关键词、天赋、可练习项与金句。

**结果稳定性**：哈希 + 种子伪随机，同一个昵称永远得到同一份结果，不会每次刷新就变。

**昵称解析有依据**：字形长度、叠字、大小写、数字、emoji、下划线、标点、动物 / 自然 / 食物 / 情绪词等特征都会参与加权。

**交互**

- 输入框占位词轮播、示例昵称快填
- 全屏扫描动画：轨道环 + 6 步逐步打勾 + 进度条
- 分数滚动、环形进度生长、雷达图逐点生长、卡片错峰入场
- 点原型形象会蹦一下并说悄悄话
- 「再夸我一句」随机彩虹屁
- 一键生成 **750×1180** 人格分享卡（Canvas 手绘，可直接下载）
- 双人合盘：两人昵称 → 匹配度 + 关系类型 + 相处建议

## 本地运行

无需构建、无需安装依赖：

```bash
open index.html          # macOS
start index.html         # Windows
```

或起一个静态服务：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

## 短链式直达

结果页支持通过 URL 参数直接生成，方便分享：

```
index.html?n=一只鹿
```

## 文件结构

```
name-aura/
├── index.html    # 页面结构与文案
├── styles.css    # 视觉系统（暖纸底 + 墨黑字 + 微信绿/紫渐变）
├── data.js       # 昵称特征库、12 原型、关系类型、彩虹屁语料
└── app.js        # 哈希、评分、雷达图、动画、Canvas 分享卡、合盘
```

## 说明

这是一个**娱乐向**产品。所有结论由昵称的字面特征推导，不对应任何真实的人格测评结论。

但底部那句是真的：愿意认真了解一个人的人，本身就值得被认真对待。
